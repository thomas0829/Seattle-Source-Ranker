3. Logical Consistency Checks

Watchers vs Stars

-   Valid comparisons: 457,223
-   Mismatches: 341,979 (≈ 74.8%)
    Conclusion:
    This high mismatch rate is expected and correct.
    GitHub no longer aligns watchers with stargazers—watchers represent
    subscribers only.
    The check successfully revealed this API semantic change.

created_at ≤ pushed_at

-   Valid timestamps: 456,988
-   Invalid cases: 3,032 (≈ 0.66%)
    Conclusion:
    These cases arise from forking behavior or imported historical
    commits, not data corruption.
    This represents normal GitHub behavior and should be treated as a
    warning, not an error.

open_issues ≥ 0

-   All values non‑negative
    Conclusion:
    No structural issues detected.

4. Summary & Professional Interpretation

1.  Field‑level data quality is excellent
    No missing or negative values for key metrics.

2.  Watchers-Star mismatch is expected
    The validation correctly surfaced the known GitHub API semantics
    change.
    This rule should be updated rather than treated as an error.

3.  Timestamp inconsistencies are benign artifacts
    Forks and historical commit imports naturally cause pushed_at <
    created_at.
    These should be classified as informational warnings.

4.  Dataset is structurally sound
    No evidence of systemic errors or corruption.
